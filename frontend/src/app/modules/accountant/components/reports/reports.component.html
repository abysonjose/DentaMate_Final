Report Guidelines

Report Types:

  • Daily Revenue: Shows all revenue transactions for a specific date
  • Monthly Income: Comprehensive monthly financial summary
  • Payment Mode: Breakdown of payments by method (Cash, UPI, Card, etc.)
  • Aging Report: Outstanding receivables categorized by age
  • Ledger Summary: General ledger entries with categorization

Export Formats:

  • PDF: Formatted reports suitable for printing and sharing
  • CSV: Data files for further analysis in spreadsheet applications

Usage Notes:

  • Reports are informational only - no approval authority
  • All data is read-only and reflects current system state
  • For discrepancies, flag items for Accounts Manager review
  • Export reports for external accounting system integration
